«Нестандартные ситуации Git»

Внимание: здесь в имени файла кириллическая буква е, и из-за похожих символов
команда может не сработать. Поэтому надёжнее восстановить файл по имени, которое
Git сам выводит, без ручного набора:

git restore -- ":(top,literal)read.mе"

Важно: команда git add -u добавит в коммит все отслеживаемые 
изменения и удаления, а не только этого файла. Если ты менял
другие файлы, сначала покажи вывод git status, чтобы
случайно не включить лишнее.
